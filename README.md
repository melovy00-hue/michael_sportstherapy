# תבנית דף נחיתה אישי (Linktree-style)

דף נחיתה חד-עמודי בעברית (RTL): Vite + TypeScript + Tailwind CSS.
מבנה הדף: Hero עם תמונת רקע -> שירותים עם סרטוני YouTube -> אודות -> המלצות -> יצירת קשר בוואטסאפ -> פוטר.
כל הטקסטים בקבצים הם placeholders - מחליפים אותם בתוכן שלך.

## איך מתחילים

```bash
npm install
npm run dev
```

## מה מחליפים

1. `src/data/config.ts` - כל התוכן: שם, טלפון, וואטסאפ, מייל, שירותים, סרטונים, צבעים.
2. תמונות בתיקיית `public/`:
   - `hero.jpg` - תמונת רקע ראשית (רוחב ~1536px)
   - `profile.png` - תמונת פרופיל (ריבועית, ~512px)
   - `video-thumb.jpg` - תמונת תצוגה לסרטון תדמית (אנכית)
   - `favicon.svg` - לוגו/אייקון
3. `src/components/App.ts` - טקסטים של אודות והמלצות (מסומנים כ-placeholders).
4. `src/main.ts` - פרטי כרטיס הביקור (vCard) בקוד ה-QR.
5. `index.html` - כותרת ותיאור לגוגל ולשיתופים.

## פרומפט מוכן ל-Claude Code

פתחו את התיקייה הזו ב-Claude Code והדביקו:

"זו תבנית דף נחיתה אישי בעברית. תתאים אותה עבורי:
אני [שם], [מקצוע]. הטלפון שלי [מספר], המייל [מייל].
השירותים שלי: [רשימה]. תחליף את כל ה-placeholders בתוכן שלי,
תשאיר את העיצוב והמבנה כמו שהם, ותריץ לי npm run dev לבדיקה."
